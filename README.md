# Video Downloader Pro 🚀

تطبيق ويب احترافي ومتكامل لتنزيل الفيديوهات والصوتيات من مختلف منصات التواصل الاجتماعي (YouTube, TikTok, Instagram, Facebook, X...) عن طريق الرابط فقط.

## 🛠️ التقنيات المستخدمة

- **Backend**: Python 3.14, FastAPI, yt-dlp, Uvicorn, SlowAPI.
- **Frontend**: HTML5, CSS3, JavaScript ES6, Bootstrap 5, Font Awesome 6, AOS Animations.
